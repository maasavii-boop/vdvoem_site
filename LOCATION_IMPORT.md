# Автоматическое наполнение локаций

v6 рассчитана на минимальное ручное обслуживание.

## Источники

### 1. OpenStreetMap / Overpass
Основной бесплатный слой: парки, музеи, театры, кино, отели, кемпинги, достопримечательности, смотровые, природные места и т.п.

### 2. Specialty discovery по региону
Отдельный запрос ищет объекты по названиям и тегам, характерным для новых загородных проектов: `глэмпинг`, `glamping`, `SPA`, `эко-отель`, `шале`, `A-frame`, `сфера`, `купол`, `ретрит`, `resort`, `база отдыха`, `домики`, `баня`, `купель`.

Такой поиск запускается на уровне региона, поэтому небольшой объект за пределами конкретного города всё равно может попасть в базу.

### 3. Автообогащение официальных сайтов
Если OSM содержит `website`, импортёр ограниченно скачивает главную страницу, кэширует её и извлекает признаки: SPA, баня, сауна, купель, бассейн, вода, лес, A-frame, сферы/купола и др.

Это не поисковый робот всего интернета: сайт объекта должен уже быть указан в открытых данных. Такой подход намеренно выбран вместо неофициального скрейпинга Яндекс Карт/2ГИС.

## Модерация

Ручная модерация НЕ обязательна. У каждого кандидата считается `quality.score`.

- `auto_publish` — автоматически публикуется;
- `review` — хранится технически, но пользователю не показывается;
- `reject` — игнорируется.

Низкокачественные объекты не требуют действий владельца сайта.

## Расписание

GitHub Action запускается ежедневно и последовательно обрабатывает небольшую пачку городов и регионов. Курсор сохраняется, поэтому база постепенно и постоянно освежается без сотен запросов одновременно.
