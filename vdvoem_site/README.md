# ВДВОЁМ — рабочий MVP сайта

Готовый full-stack проект без ИИ и без платной базы данных.

## Что внутри

- `public/` — весь фронтенд: HTML, CSS и JavaScript.
- `server.js` — backend на Node.js + Express.
- `data/database.json` — 100 идей и 106 локаций.
- `/api/spin` — API, которое фильтрует базу и случайно выбирает результат.
- Избранное хранится в `localStorage` браузера — аккаунты не нужны.

## 1. Что установить

Установите **Node.js 20 или новее** с официального сайта nodejs.org.

Проверка после установки:

```bash
node -v
npm -v
```

## 2. Как запустить локально

Откройте терминал в папке проекта и выполните:

```bash
npm install
npm run dev
```

Откройте в браузере:

```text
http://localhost:3000
```

Остановить сервер: `Ctrl + C`.

## 3. Как устроен backend

Основной endpoint:

```text
POST /api/spin
```

Пример тела запроса:

```json
{
  "city": "Москва и область",
  "budget": "До 5000 ₽",
  "duration": "2–4 часа",
  "category": "Романтика",
  "trip": {}
}
```

Для мини-путешествия frontend может передавать:

```json
{
  "category": "Мини-путешествие",
  "trip": {
    "format": ["глэмпинг"],
    "setting": ["у воды"],
    "facilities": ["баня"],
    "distance": ["до 30 км"],
    "tripLength": ["1 ночь"]
  }
}
```

## 4. Как менять идеи и места

Откройте:

```text
data/database.json
```

Чтобы добавить идею — добавьте объект в массив `ideas`.
Чтобы добавить место — добавьте объект в массив `locations`.
После сохранения перезапустите сервер.

## 5. Как поменять дизайн

- Главная разметка: `public/index.html`
- Цвета, размеры, мобильная версия: `public/styles.css`
- Вращение барабана, фильтры, избранное: `public/app.js`

Основные цвета находятся в самом начале `styles.css` в блоке `:root`.

## 6. Как выложить сайт в интернет — самый простой вариант

### Render

1. Создайте бесплатный аккаунт на GitHub.
2. Создайте новый репозиторий и загрузите туда эту папку.
3. Создайте аккаунт на Render.
4. `New` → `Web Service` → подключите GitHub-репозиторий.
5. Настройки:
   - Runtime: `Node`
   - Build Command: `npm install`
   - Start Command: `npm start`
6. Нажмите Deploy.

Render выдаст адрес вида:

```text
https://your-project.onrender.com
```

Свой домен можно подключить позже.

## 7. Что не нужно покупать

Для текущей версии не нужны:

- OpenAI API;
- база данных;
- отдельный backend-сервис;
- платная карта;
- авторизация;
- CMS.

Express одновременно отдаёт frontend и API.

## 8. Перед публичным запуском

Для локаций желательно вручную проверить актуальность названий, адресов и доступности. Для отелей и глэмпингов не храните фиксированную стоимость: она зависит от даты и дня недели.
