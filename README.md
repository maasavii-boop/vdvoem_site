# ВДВОЁМ v8

Рабочий full-stack MVP без платного ИИ и без внешней базы данных. Node.js 20+.

## Запуск

```bash
npm start
```

При первом запуске `prestart` пытается получить полный каталог городов России и сохранить его в `data/russia-cities.json`. Если сеть недоступна, сайт запускается с резервным списком, а каталог можно обновить позже:

```bash
npm run sync:cities
```

Открыть: http://localhost:3000

## Что нового в v8

- Москва / Московская область / Москва и МО + выбор любого города России.
- Полный список городов строится автоматически и хранится локально.
- Локации для всех городов наполняются без ручного создания market-файлов.
- Отдельный региональный поиск малоизвестных глэмпингов, SPA, шале, A-frame, сфер, купелей, бань, баз отдыха и ретритов.
- Автоматическое обогащение найденных объектов с их официальных сайтов: признаки SPA, бани, купели, воды, леса, A-frame и т.д.
- Автооценка качества: хорошие объекты публикуются сами, сомнительные просто не попадают пользователям.
- Ссылки на официальный сайт и карты формируются на фронте автоматически.
- Ежедневный GitHub Action обновляет каталог порциями, не перегружая общественный Overpass API.

## Автообновление всей России

Обычный режим:

```bash
npm run sync:russia
```

По умолчанию один запуск обрабатывает 24 города и 6 регионов. Курсоры сохраняются в `data/sync-state.json`, поэтому следующий запуск продолжит с нового места. При ежедневном расписании весь городской каталог циклически обновляется примерно за несколько недель, а региональный слой глэмпингов/SPA — быстрее.

Размер пачек можно изменить:

```bash
CITY_SYNC_BATCH=40 REGION_SYNC_BATCH=8 npm run sync:russia
```

`sync:russia:full` предназначен только для собственной инфраструктуры/Overpass и не рекомендуется против бесплатного публичного сервера.

## Структура

- `data/core/ideas.json` — универсальные идеи.
- `data/markets/` — вручную отобранные Москва и МО.
- `data/russia-cities.json` — каталог городов.
- `data/city-locations/` — автонаполняемая база по городам.
- `data/inbox/` — технические кандидаты/диагностика; ручная обработка не обязательна.
- `scripts/sync-cities.js` — каталог городов.
- `scripts/import-osm.js` — OSM + specialty discovery + website enrichment.
- `scripts/sync-russia.js` — ротационное обновление всей страны.

## Важное

Для production задайте свой корректный `VDVOEM_USER_AGENT` с контактным email. Публичный Overpass — общий ресурс; проект использует кэш, последовательные запросы и небольшие ежедневные пачки.

## Контроль без админки

Состояние автокаталога можно посмотреть по адресу:

```text
/api/v1/catalog/status
```

Он показывает размер каталога городов, сколько городов уже получили локации, сколько регионов прошло specialty-синхронизацию и когда был последний проход. Автоматически импортированные OSM-объекты, которые три последовательных обновления больше не встречаются в источнике, скрываются из пользовательской выдачи.
